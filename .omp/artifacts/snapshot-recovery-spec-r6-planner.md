New Store method:
  func (s *Store) RecoverRejected(now func() time.Time) (RecoveryResult, error)
type RecoveryResult struct { Recoveries []Recovery; RetentionFailures []RetentionFailure }; type Recovery struct { Original, QuarantinePath, Reason string }; type RetentionFailure struct { Family, QuarantinePath string }; Reason ∈ the five finite values; package constants QuarantineKeep = 5 and quarantine name prefixes. Contract per file (snapshot.json then prompts.json), executed while the Store's writer flock is held, once per process:
1) Lstat(path): ErrNotExist → skip (R6 absent subcase). Mode is not regular → fatal error wrapping new sentinel ErrSnapshotUnrecoverable with the path (R3).
2) Load()/LoadPrompts(): nil → skip (trusted set, R6 preserved); ErrNoSnapshot → skip; ErrCorrupt → reason from sentinel (decode incl. trailing data→corrupt_json, checksum→checksum_mismatch, unsupported schema→unsupported_schema, validate→validation_failure); any other error → read_error (regular file already proven by step 1). The file read inside Load goes through an unexported package variable (default os.ReadFile) so tests inject read failures deterministically.
3) Rename os.Rename(path, quarantine) via an unexported seam variable (default os.Rename); rename failure → fatal, original untouched. On rename success run syncDirectory via an unexported seam (default internal/storage/store.go:309 syncDirectory); sync failure → fatal with the bytes at the quarantine path and the original absent (R3); on success record the Recovery in the result.
4) Retention (only after a successful rename, for that family): list entries; keep ONLY names matching the strict grammar prefix + RFC3339Nano-UTC timestamp ending in literal `Z` + `.json`, parsed with time.Parse; exclude the quarantine file this run just created by exact path; sort remaining kept names by parsed timestamp newest-first; unlink beyond QuarantineKeep; unlink failure → append RetentionFailure{Family, QuarantinePath} with the first failing path of that family, continue with remaining unlinks, never fail startup. Non-conforming entries are never sorted, counted, or unlinked.
Fatal ordering (H4 closure, carried): accumulation — every successful quarantine performed before a fatal is returned in RecoveryResult alongside the fatal error; a fatal stops all further mutation immediately.
