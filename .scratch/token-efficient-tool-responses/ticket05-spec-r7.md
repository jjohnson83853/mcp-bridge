Under the default bounds (1536/512/6, internal/config/bounds.go:226-236, :221) the derived budget is ≥ 512 encoded array bytes; 512 is the DOCUMENTED FLOOR (R6-7), the derived budget is binding. A request exceeding the budget is a deterministic pre-dispatch invalid_arguments rejection (reason `not_supported`). The MAXIMAL LEGAL REQUEST is the largest fields array satisfying BOTH the count/length/alphabet bounds AND the derived budget (computed, never assumed). Unknown-field rejection requires a non-empty list whose items all lack a requested field.

## 4. DESIGN
Selected approach (unchanged in kind; schema + threading completed): pure field-projection engine in NEW package-private `internal/service/field_projection.go`, invoked from TWO call sites — `callTool` at the decodeUpstreamResult call site (tools.go:1000) and `boundDirectExecution.call` (direct_execution.go:30) between its decode (:53) and result construction (:60-64) — in both cases before `t.boundedCallToolResult` (direct call site :65).
- Single-transformed-result rule (F1/R6-2, both paths): APPLY → one transformed result feeds every downstream derivation (multiplexer: the WHOLE `upstream_result` member re-marshaled + returned result + envelope disclosure; direct path: returned result's Content + rewritten payload-bearing structuredContent member + reserved-member disclosure); SKIP/pass-through → original bytes/value flow unchanged.
- NORMATIVE DISCLOSURE SCHEMA (R6-1, both carriers): `{v:1, applied, entry, mode, fields, reason?}`, reason required iff applied=false; `v` fixed 1; entry = entryID or `not_allowlisted`; mode ∈ default|fields|full; reason ∈ the closed 12-value enum. AC1's oracle asserts this exact shape.
- NORMATIVE D-TABLE (F-B, 21 rows, per-row outcome/reason/channel; P = payload member on the row's path, L = one log record, C = counter with outcome domain {applied, skipped, rejected}, R6-6):
  1. no match | absent/empty | — | — | pass-through | — | NONE (byte-identical, R7)
  2. no match | full | — | no error | pass-through | full_requested | P + C(skipped)
  3. no match | full | — | error | pass-through | upstream_error | P + C(skipped)
  4. no match | fields | — | — | REJECT pre-dispatch | not_supported | L + C(rejected)
  5. match | absent | select absent | no error | shape ok | APPLY | — | P + C(applied)
  6. match | absent | select absent | no error | carrier failure — non-list | unparseable wrapper | non-mirrorable payload-bearing SC | ANY non-object item (WHOLE-LIST skip, open question) | SKIP | payload_unparseable | payload_shape_unexpected | structured_content_not_mirrorable | item_shape_unexpected (per failure) | P + L + C(skipped)
  7. match | absent | select absent | no error | shape ok, EVERY item misses ALL default fields (aggregate) | SKIP | item_shape_unexpected | P + L + C(skipped)
  8. match | absent | select absent | error | — | pass-through unchanged | — | NONE (AC6(a))
  9. match | absent | select present | no error | — | SKIP | upstream_select_present | P + L + C(skipped)
  10. match | absent | select present | error | — | pass-through unchanged | — | NONE (AC6(a))
  11. match | full | — | no error | — | pass-through | full_requested | P + C(skipped)
  12. match | full | — | error | — | pass-through | upstream_error (N6) | P + C(skipped)
  13. match | fields | select absent | no error | EMPTY list | APPLY | — | P + C(applied)
  14. match | fields | select absent | no error | ok non-empty | dispatch → shape gate → field validation → APPLY | — | P + C(applied)
  15. match | fields | select absent | no error | carrier failure (as row 6) | SKIP | per-failure reason | P + L + C(skipped)
  16. match | fields | select absent | no error | ok non-empty, requested field in no item | REJECT post-dispatch | unknown_field_selection | L + C(rejected)
  17. match | fields | select absent | error | — | pass-through unchanged | upstream_error | P + C(skipped)
  18. match | fields | select present | — | — | REJECT pre-dispatch | select_conflict | L + C(rejected)
  19. any | fields over the runtime budget | — | — | — | REJECT pre-dispatch | not_supported | L + C(rejected)
  20. direct path | match | select absent | no error | shape ok, reserved key ALREADY present upstream | SKIP (never overwrite) | disclosure_key_collision | L + C(skipped) only — payload carrier colliding (AC6(d) states this channel)
  21. malformed request | any entry | — | — | REJECT pre-dispatch | malformed_request | L + C(rejected)
